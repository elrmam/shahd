# دعوة زفاف عبد الرحمن وشهد — Cinematic Edition

موقع دعوة تفاعلي مستقل باستخدام React + Vite، مصمم للموبايل أولًا. الألوان: أبيض لؤلؤي، فضي، ذهبي، أسود، وأحمر عنابي.

## التشغيل

```bash
npm install
npm run dev
```

## إضافة الأغنية
ضع أغنيتك باسم `wedding-song.mp3` داخل `public/music/`. سيحاول الموقع تشغيلها بعد الضغط على «افتح الدعوة» (تفاعل المستخدم يسمح بالتشغيل على أغلب المتصفحات). يوجد زر عائم للتحكم في الصوت. إذا لم تضف الملف، سيظل الموقع يعمل دون موسيقى.

## تعديل بيانات المناسبة
افتح `src/App.jsx`، وعدّل كائن `EVENT` أعلى الملف. عند تغيير التاريخ أو الأسماء لمناسبة جديدة، راجع أيضًا نصوص الدعوة الثابتة وتاريخ ملف التقويم في `downloadCalendar`.

## الميزات
- افتتاحية تفاعلية مع انتقال ستارة، وتفاصيل ذهبية وحمراء.
- حركات دخول الأقسام، شريط أسماء متحرك، انتقالات الصور، وتأثيرات دقيقة.
- عد تنازلي بالأيام والساعات والدقائق والثواني فقط.
- تفاصيل المناسبة ورابط خريطة واحد داخل بطاقة القاعة.
- زر إضافة للتقويم (ملف ICS)، وزر مشاركة الدعوة مع نسخ الرابط كبديل.
- معرض صور مع تكبير، وصور تجريبية من Unsplash تتطلب اتصال إنترنت.
- دعم تقليل الحركة للمستخدمين الذين يفعّلون Reduced Motion.

## النشر على Vercel
ارفع ملفات المشروع إلى GitHub (بدون `node_modules`)، واستورد الريبو في Vercel مع Framework: Vite وBuild: `npm run build` وOutput: `dist`.

**تنويه:** صور الزفاف المستخدمة صور تمثيلية وليست صورًا حقيقية للعروسين. ووقت نهاية الموعد في ملف التقويم محدد تقديريًا الساعة 11 مساءً.
